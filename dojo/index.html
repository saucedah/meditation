⚡ Slash commands

  • /help — get help
  • /clear — reset the conversation
  • /config — open settings UI
  • /agents — list subagents
  • /init — generate CLAUDE.md
  • /review — review a PR
  • /security-review — audit current diff
  • /verify — run app to confirm a fix

🪝 Hook events

  • SessionStart — once per session
  • UserPromptSubmit — every user message
  • PreToolUse / PostToolUse — around tools
  • Stop — turn ends
  • Notification — idle

🛡️ Permissions

  • Bash(npm:*) — allow any npm command
  • Read(./src/**) — allow reads under src
  • Modes: default, acceptEdits, bypassPermissions
  • Settings: user → project → local (merge order)

🛠️ Tool picks

  • View file → Read (not cat)
  • Edit file → Edit (not sed)
  • Create file → Write (not echo >)
  • Long task → Bash run_in_background
  • Independent calls → one message, multiple blocks

🥷 Subagents

  • Explore — read-only code search
  • Plan — architecture planning
  • code-review — second opinion on a diff
  • general-purpose — catch-all
  • Prompt must be self-contained — no memory of parent

🌳 Git rules

  • Never amend after pre-commit fails → new commit
  • Stage by name; avoid git add -A
  • Inspect: status + diff + log in parallel
  • PR body via HEREDOC for formatting
